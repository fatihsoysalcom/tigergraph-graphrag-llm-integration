# TigerGraph GraphRAG LLM Integration

This Python script demonstrates a simplified GraphRAG system using mock LLM and TigerGraph clients. It shows how to retrieve information from a knowledge graph (simulated) and augment an LLM's prompt to generate more contextually relevant answers.

## Language

`python`

## How to Run

Run the script using: python graphprobe_ai.py
